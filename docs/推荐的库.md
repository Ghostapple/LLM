# 推荐的库

- [datawhalechina/happy-llm](https://github.com/datawhalechina/happy-llm)：从零开始讲解大语言模型的核心原理与实践流程，适合入门。
- [datawhalechina/self-llm](https://github.com/datawhalechina/self-llm)：更偏部署、微调与实际使用，适合上手做实验。
